# C - Binary Trees

This repository contains our solutions and learning progress for the **C - Binary Trees** project.

## Authors

* **Khaled Fahd Alyahya**
* **Ahmed Mamdouh Alrifai**

The goal of this project is to understand how binary trees work in C, including how nodes are connected using pointers and how tree structures are represented in memory.

Topics covered include:

* Binary Trees
* Binary Tree vs Binary Search Tree
* Parent, child, root, and leaf nodes
* Left and right child pointers
* Tree depth and height
* Tree size
* Tree traversals:

  * Pre-order
  * In-order
  * Post-order
* Leaves and internal nodes
* Balance factor
* Full and perfect binary trees
* Siblings and uncles
* Recursion in tree structures

The main focus of this project is to understand the **logic and memory model behind tree data structures**, not only to implement the functions.
